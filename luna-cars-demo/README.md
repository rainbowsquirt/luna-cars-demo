# LUNA CARS · демо-прототип

Концепт редизайна страницы LUNA CARS (VisionLabs). Не официальный сайт.

Статичный сайт без сборки: `index.html`, `styles.css`, `main.js`, шрифты Medeo в `fonts/` (OFL 1.1).
Анимации: GSAP + ScrollTrigger, плавный скролл: Lenis (подключены с CDN).

Локально: открыть `index.html` или `npx serve .`
Деплой: Vercel, Framework Preset = Other, без команды сборки.
